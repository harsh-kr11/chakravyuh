# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

We are committed to a harassment-free, welcoming, and respectful community for
everyone. Be excellent to each other. Report unacceptable behaviour to the
maintainers via a private security/contact channel (see `SECURITY.md`).
Maintainers may take any action they deem appropriate, up to and including a
temporary or permanent ban.
